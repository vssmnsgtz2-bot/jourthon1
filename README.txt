Jourthon Nutrition Website — Static Deployment Package
====================================================

This package is a pure HTML/CSS/JS static website. No framework, Node.js, npm, or build step is required.

FILE STRUCTURE
--------------
index.html          — Homepage
about.html          — About Us page
services.html       — Services / Solutions page
quality.html        — Quality & Compliance page
contact.html        — Project inquiry and contact page
style.css           — Shared stylesheet for all pages
script.js           — Shared navigation and scroll animation script
images/             — All image assets used by the website

DEPLOYMENT
----------
Upload all files and folders in this package to the root of your GitHub Pages repository.
For a user/organization site, upload to the main branch root. For a project site, upload these files to the branch/folder configured in GitHub Pages.

No build step is required. Open index.html locally to preview.

MODIFICATION NOTES
------------------
1. All page links use relative .html paths, so the website works on GitHub Pages project paths.
2. The contact form is static and opens the visitor's email client. Connect it to a form service if you need online submissions.
3. Keep all images inside the images/ folder and reference them with relative paths.
4. The website language is English only.
5. The visual style preserves Jourthon's original blue/white professional identity while improving the information framework and inquiry path.
